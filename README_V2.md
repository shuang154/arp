# ARP Spoofer Pro V2.0 - 分级递进式攻击系统

## 🚀 系统升级概述

本次升级将原有的"广撒网"攻击系统转变为"智能化分级递进式攻击系统"，实现了从"工具"到"智能体"的革命性进化。

## 🎯 核心设计理念

### 从"无差别攻击"到"精准狙击"
- **传统模式**: 发现设备 → 立即全面攻击 → 长时间占用
- **智能模式**: 发现设备 → 轻量侦察 → 价值评估 → 精准升级 → 立即撤退

### 分级递进策略
1. **🕵️ 侦察阶段**: 60秒轻量级MiTM，观察目标行为
2. **🎯 价值判断**: 检测高价值事件（端口801、目标服务器访问等）
3. **⬆️ 攻击升级**: 发现价值目标后升级为60秒全面攻击
4. **🏆 精准撤退**: 捕获凭据后立即恢复网络
5. **⏰ 自动释放**: 无价值目标自动超时释放

## 📋 主要修改内容

### Python监督者升级 (决策大脑)

#### 1. 配置系统增强
- **文件**: `config/config.yaml`, `python_supervisor/config.py`
- **新增配置**:
  ```yaml
  attack:
    strategy:
      scouting_duration: 60       # 侦察窗口时间
      full_attack_duration: 60   # 全面攻击时间
      high_value_ports: [801, 443] # 高价值端口
  ```

#### 2. 状态缓存重构
- **文件**: `python_supervisor/state_cache.py`
- **新增功能**:
  - `get_attack_info()` - 获取攻击状态信息
  - `upgrade_attack_session()` - 攻击会话升级
  - 支持攻击类型: `scouting`, `full_attack`, `standard`

#### 3. 攻击协调器重写
- **文件**: `python_supervisor/attack_coordinator.py`
- **核心逻辑**:
  - `_handle_arp_analysis()` - ARP查询 → 启动侦察
  - `_handle_http_analysis()` - HTTP分析 → 价值判断与升级
  - `_is_high_value_event()` - 高价值事件检测

### C++核心升级 (高效执行者)

#### 1. ARPSpoofer增强
- **文件**: `cpp_core/src/arp_spoofer.h`, `cpp_core/src/arp_spoofer.cpp`
- **新增功能**:
  - 支持定时攻击 (`duration_seconds`)
  - 攻击类型标识 (`attack_type`)
  - 自动定时器线程 (`timer_thread_func`)
  - 攻击升级支持 (从侦察升级到全面攻击)

#### 2. IPC通信升级
- **文件**: `cpp_core/src/ipc_manager.h`, `cpp_core/src/ipc_manager.cpp`
- **新增字段**:
  - `attack_type` - 攻击类型
  - `reason` - 决策原因
  - 完整支持duration参数解析

#### 3. 主控制器适配
- **文件**: `cpp_core/src/main.cpp`
- **修改**: START_SPOOF命令处理，支持新参数传递

## 🔄 智能工作流程

### 典型场景演示

1. **📱 新设备接入**
   ```
   设备A连接WiFi → 发送ARP网关查询
   ```

2. **🕵️ 启动侦察**
   ```
   Python: "检测到新设备192.168.1.100，启动60秒侦察"
   C++: 启动轻量级MiTM + 60秒定时器
   ```

3. **👁️ 行为监控**
   ```
   目标流量 → Python分析 → 无价值行为
   60秒后 → 定时器到期 → 自动恢复网络
   ```

4. **🎯 价值发现**
   ```
   目标访问121.248.150.37:801 → Python: "高价值事件!"
   发送升级命令 → C++: 重置定时器为60秒全面攻击
   ```

5. **🏆 凭据捕获**
   ```
   截获用户名/密码 → Python: "任务完成!"
   立即发送RESTORE命令 → 取消定时器 → 恢复网络
   ```

## 🔧 配置说明

### 关键配置项
```yaml
attack:
  strategy:
    scouting_duration: 60         # 侦察时间(秒)
    full_attack_duration: 60     # 全面攻击时间(秒)
    high_value_ports: [801, 443] # 高价值端口列表
    immediate_restore_on_success: true # 成功后立即恢复

network:
  target_server: "121.248.150.37"  # 重点监控的服务器
  target_ports: [80, 443, 8080, 801] # 监听端口
```

### 高价值事件定义
- 访问指定目标服务器 (`target_server`)
- 访问高价值端口 (`high_value_ports`)
- 可扩展其他检测规则
